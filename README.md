# 科技平权：生成式人工智能创新驱动下的社会公平与发展

围绕生成式人工智能能否让不同群体公平受益这一问题，从个人、行业、地区和国家四个层面，结合文本分析、统计建模与可视化，研究技术获得能力、成果转化能力及数字鸿沟。项目获 2025 年中国大学生计算机设计大赛全国二等奖。

## 研究内容

| 层面 | 关注问题 | 主要方法 |
| --- | --- | --- |
| 个人 | 公众如何看待生成式 AI，不同群体的关注点有何差异 | 中文分词、词频与词云、SnowNLP 情感分析、LDA 主题建模 |
| 行业 | 企业技术采纳、专利转化与合作资源如何分布 | CRITIC 赋权、基尼系数、回归分析、随机森林、合作网络与 PageRank |
| 地区 | 省际 AI 发展差异及其影响因素 | 综合评价、模型对比、PCA、SHAP 与消融分析 |
| 国家 | 全球 AI 竞争格局与科技平权的关系 | 指数合成、相似性网络、社区划分与回归分析 |

分析将“能否获得技术”与“能否转化技术红利”区分开来，尝试从多尺度数据中识别资源集中、合作壁垒和发展差异。

## 主要发现

- 技术普及并不意味着所有群体同等受益，使用门槛、数字素养与风险担忧仍存在差异。
- 企业合作网络与资源配置、地区人才和创新基础，均是理解技术转化差异的重要线索。
- AI 发展与科技平权需要共同推进，降低使用门槛、提升能力建设和促进合作是重要方向。

结论基于特定样本与指标设定，反映样本中的统计关系和研究观察，不代表普遍因果结论。

## 使用说明

1. 使用 Python 与 Jupyter 打开所需分析笔记本。
2. 根据模块安装依赖：常用 pandas、NumPy、Matplotlib、Seaborn、scikit-learn；文本分析使用 jieba、SnowNLP、gensim、pyLDAvis、wordcloud；其他模块按需使用 NetworkX、statsmodels、linearmodels、GeoPandas、Plotly、pyecharts、SHAP 等。
3. 下载微博数据，调整输入路径、输出路径与中文字体配置。
4. 按笔记本的处理顺序准备数据并运行，查看统计结果、模型输出和图表。

仓库保留了研究阶段的独立笔记本，尚未统一为一键运行流程。部分笔记本依赖额外的原始表、处理后数据、停用词表、设备价格表或词云遮罩图；这些文件并非都已包含在仓库或上述微博数据下载中，运行前需逐项准备。
